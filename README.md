# Wallet Diary – Personal Expense Tracking and Budget Management System

Wallet Diary is a Java-based web application designed to help users record, manage, and monitor their daily expenses through a simple and user-friendly interface.

## Features

- Add new expenses
- View recorded expenses
- Search expenses
- Update expense details
- Delete expenses
- View expense summaries
- Store expense records in a MySQL database
- Web-based user interface

## Technologies Used

- **Backend:** Java 17
- **Database:** MySQL 8.0
- **Database Connectivity:** JDBC
- **Frontend:** HTML, CSS, JavaScript
- **Build and Dependency Management:** Maven
- **Development Environment:** Visual Studio Code

## Project Structure

- `src/main/java` – Java application, DAO, model, server and utility classes.
- `src/main/resources/db` – Database schema.
- `web` – Frontend files (HTML, CSS and JavaScript).
- `docs` – Project documentation.
- `pom.xml` – Maven configuration.

## Database

The application uses MySQL to store expense information.

Database configuration is maintained separately in a local properties file and is not included in the public repository.

## How to Run

1. Install Java 17.
2. Install Maven.
3. Install and configure MySQL.
4. Configure your local database credentials.
5. Create the required database using the SQL schema.
6. Resolve Maven dependencies.
7. Run the application using the configured Java entry point.

## Project Status

The project includes Java backend components, JDBC database connectivity, expense management operations and a web-based interface. Further UI enhancements and testing are planned.
